# 使用說明

此專案提供離線 PDF 座標預覽工具，讓使用者上傳 PDF 後，在預覽畫面中以滑鼠左鍵點擊任一位置即可立即得知該點在 PDF 座標系中的 X、Y 數值。

## 目錄結構

```
./index.html             # 主頁面，含樣式與互動邏輯
./vendor/pdfjs/pdf.min.js
./vendor/pdfjs/pdf.worker.min.js
```

## 執行需求

- 任意現代瀏覽器 (Chrome、Edge、Firefox、Safari 等)。
- 可選：Python 3（若要啟動簡易本地伺服器）。

> **注意**：大多數瀏覽器不允許 `file://` 直接載入 Web Worker。若在本地直接開啟 `index.html` 無法渲染 PDF，請依下列步驟啟動簡易伺服器。

## 啟動步驟

1. 進入專案資料夾：
   ```bash
   cd /Users/sonic711/pdfDemo
   ```
2. 啟動簡易伺服器（以 Python 為例）：
   ```bash
   python3 -m http.server 8000
   ```
3. 於瀏覽器開啟 `http://localhost:8000/index.html`。

## 使用方式

1. 點擊「選擇 PDF 檔案」上傳本地 PDF。
2. 頁面載入完成後，畫面會顯示每一頁的預覽。
3. 在任一頁面上以滑鼠左鍵點擊想取得座標的位置：
   - 上方座標框會顯示 `頁碼 N | X: xxx, Y: yyy`。
   - 瀏覽器會彈出 alert 顯示相同資訊，可方便記錄。
4. 若需重新測量，直接在預覽畫面其他位置點擊即可。

## 常見問題

- **看不到 PDF 或座標**：
  - 確認是否從 `http://localhost:8000` 之類的網址開啟，而非直接點開檔案。
  - 確認瀏覽器允許讀取本地檔案。若是公司環境，可能需要允許權限。
- **座標與預期不符**：
  - 本工具輸出的是 PDF 內建座標系（左下角為原點）。如需轉換為其他座標系，請自行計算或修改程式碼。

## 自訂與擴充

- 想更換字型或顏色，可直接編輯 `index.html` 內的 `<style>` 區塊。
- 若希望一次載入大量 PDF，可於 `viewer` 區塊或渲染邏輯中加入分頁或 lazy load。
- 需要紀錄座標點的話，可在 `pointerdown` 事件中改為把資料推入清單或送往後端。
